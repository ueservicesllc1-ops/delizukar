# Productos/APIs a Seleccionar en UPS Developer Portal

## Productos Necesarios para Envíos

### ✅ OBLIGATORIOS:

1. **Rating API**
   - Para obtener tarifas de envío
   - Permite calcular costos antes de crear la etiqueta

2. **Shipping API**
   - Para crear etiquetas de envío
   - Permite comprar etiquetas directamente

### ⚠️ OPCIONALES (pero recomendados):

3. **Tracking API**
   - Para rastrear paquetes después del envío
   - Útil para mostrar el estado del envío a los clientes

4. **Address Validation API**
   - Para validar direcciones antes de crear envíos
   - Ayuda a evitar errores de dirección

## Pasos en el Portal

1. En la sección **"Products Included In This App"**, busca y selecciona:
   - ✅ **Rating**
   - ✅ **Shipping**
   - ✅ **Tracking** (opcional pero recomendado)
   - ✅ **Address Validation** (opcional pero recomendado)

2. Haz clic en **"Create App"** o **"Save"**

3. Después de crear la app, UPS te mostrará:
   - **Client ID** (Consumer Key)
   - **Client Secret** (Consumer Secret)
   - **App ID** (puede ser necesario)

## Después de Crear la App

Una vez que tengas las credenciales, compártelas conmigo y las integraré en el código.
